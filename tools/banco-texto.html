What is this page? / ¿Qué es esta página?

A side-by-side comparison bench for WebEdiThor's text animations and button hovers. It is not part of the editor and nothing in the build uses it. Some animation problems (blurry text, a small jump when an animation ends) only show up on a real screen with GPU compositing, and automated headless tests cannot see them, so each technique is shown here to judge by eye.

How to use it: open this file in your browser (double-click, no server needed). Try 100 % and 125 % zoom and slow the animations down with the speed buttons. Use each card's «Repetir» / «Mantener» button. Compare in Firefox and Chrome: they behave differently. The techniques that won are already in the editor; this page is kept so you can run the same comparison on your own screen.

Banco de comparación a ojo para las animaciones de texto y los hovers de botón. No forma parte del editor. Ábrelo con doble clic, prueba a 100 % y a 125 % de zoom, baja la velocidad y compara en Firefox y en Chrome.

1 · Letras al aparecer («Por letras»)

Cada tarjeta es una técnica distinta; dentro, una palabra sola («Galería») y varias («Lo que hacemos»). La animación es la del editor: sube 30 px y aparece, 0,7 s, con cascada por letra (tope 2 s). Cada tarjeta tiene su «Repetir». Las de la etiqueta amarilla «ronda 2» (V7 a V13) son las nuevas.

2 · Botón «Ver más» con hover que se agranda

Pasa el ratón por encima. Con velocidad 0,1x la transición dura 2 s y se ve el cambio con calma. «Mantener agrandado» deja el botón en el estado de hover para mirarlo quieto (y al soltarlo, hace la animación de vuelta). Cada fila lleva el botón «Grande» (18 px), el «Mediano» (16 px) y uno extra de 28 px. Las de «ronda 2» (V6 a V10) buscan que el texto no cambie de tamaño.

3 · Ronda 3 · Elevar, Agrandar, Encoger e Inclinar ronda 3

Cada tarjeta lleva cuatro botones «Ver más»: Grande (18 px), Mediano (16 px), Extra (28 px) y «Solo texto» (18 px, sin fondo ni borde: así es el botón sin caja del editor). Las tarjetas «Actual del editor» llevan el CSS que genera el exportador, copiado tal cual (lista de transition completa, position:relative y ::after de zona anti-parpadeo donde el editor los pone). Velocidad y «Mantener» funcionan igual que arriba. Aquí no hay veredicto: lo decides tú a ojo, con zoom por encima del 120 % en Firefox y en Chrome.

Limitación del truco del fondo («b»): solo sirve si el botón tiene fondo o borde visible, porque lo que escala es ese fondo/borde. Con un botón solo de texto no hay nada que escalar: en las tarjetas «b» la muestra «Solo texto» enseña lo único posible, que es que APAREZCA un fondo suave y crezca. Eso ya no es «el mismo efecto sin tocar el texto», es otro efecto (como «Fondo que crece» del editor). Si quieres que un botón solo de texto se mueva, el texto tiene que moverse, y vuelve el riesgo de borrosidad.
